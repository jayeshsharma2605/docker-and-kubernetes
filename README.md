## Learning approach

1. Study the lecture's concept in simple language.
2. Follow the visual diagrams and request flows.
3. Run only commands you understand in an appropriately isolated local learning environment.
4. Compare behavior with [official Docker documentation](https://docs.docker.com/).
5. Answer the revision questions and explain each concept without the notes.

## Notes on accuracy and security

Docker and Kubernetes change over time. Verify current CLI syntax, platform support, API versions, security practices and examples before applying instructions to production. Do not share course login credentials, private keys, container registry passwords, or cluster access tokens.
